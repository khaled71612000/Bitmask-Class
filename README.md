## Overview

A C++ bitmask utility class demonstrating bitwise operations (AND, OR, XOR, NOT), flag manipulation, and efficient multi-state storage.

## Getting Started

```bash
git clone https://github.com/khaled71612000/Bitmask-Class.git
cd Bitmask-Class
gcc -o output main.c -Wall -std=c99
./output
```
